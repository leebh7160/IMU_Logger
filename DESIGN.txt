1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Purpose: High-speed data logger for STM32 IMU/GPS system (104Hz target)
Key Features:
- Port connection verification
- Real-time performance monitoring
- Data integrity validation
- CSV logging with memory buffering
- Backend integration capability

Target Performance:
- Sampling Rate: 104Hz (STM32 output rate)
- Data Loss: < 1%
- Memory Usage: < 100MB for 10 minutes
- CSV Write Time: < 1 second for 10 minutes data

3. MODULE SPECIFICATIONS
--------------------------------------------------------------------------------

3.1 CONNECTION_MANAGER.PY
--------------------------
Class: ConnectionManager
Purpose: Manage serial port connection and verification

Key Methods:
- scan_ports() -> List[PortInfo]
  * Scan all available serial ports
  * Identify STM32 devices by VID/PID
  * Return sorted list with STM32 priority

- test_connection(port: str) -> ConnectionTestResult
  * Stage 1: Attempt to open port
  * Stage 2: Receive data for 3 seconds
  * Stage 3: Validate data format
  * Return detailed test results

- verify_continuous_data() -> bool
  * Monitor data stream for 10 seconds

  * Calculate average Hz
  * Detect data interruptions
  * Check GPS signal presence

- optimize_settings() -> None
  * Adjust serial buffer size
  * Optimize timeout values
  * Configure for maximum throughput


3.2 SERIAL_READER.PY
---------------------
Class: OptimizedSerialReader
Purpose: High-speed serial data collection

Key Features:
- Non-blocking read with in_waiting
- 65KB buffer size
- Batch processing (multiple lines per read)
- Incomplete line handling
- 1ms timeout for responsiveness

Key Methods:
- connect(port, baudrate) -> bool
- read_batch() -> List[str]
- get_buffer_status() -> Dict
- disconnect() -> None


3.3 DATA_VALIDATOR.PY
----------------------
Class: DataValidator
Purpose: Validate received data format and integrity

Supported Formats:
- IMU: "IMU: Acc[x,y,z] Gyro[x,y,z]"
- GPS: "GPS: Lat[lat] Lng[lng] Status[status]"
- ESKF: "ESKF: IMU[...] Pos[...] Att[...]"

Key Methods:
- validate_line(line: str) -> ValidationResult
- check_data_integrity(buffer: List) -> IntegrityReport
- get_format_statistics() -> FormatStats


3.4 PERFORMANCE_MONITOR.PY
---------------------------
Class: PerformanceMonitor
Purpose: Track real-time performance metrics

Metrics Tracked:
- Current sampling rate (Hz)
- Average/Min/Max Hz
- Packet drop count
- Buffer overflow risk
- Timing consistency

Key Methods:
- update(timestamp, buffer_size) -> None
- get_current_hz() -> float
- get_statistics() -> PerformanceStats
- detect_anomalies() -> List[Anomaly]


3.5 CSV_LOGGER.PY
-----------------
Class: CSVLogger
Purpose: Efficient CSV file writing

Features:
- Memory buffering (no real-time I/O)
- Dual CSV output (raw + ESKF)
- Automatic filename generation
- Batch writing on stop

CSV Headers:
timestamp, accel_x, accel_y, accel_z, gyro_x, gyro_y, gyro_z,
gps_available, gps_lat, gps_lng, gps_alt, satellites,
eskf_pos_x, eskf_pos_y, eskf_pos_z, eskf_roll, eskf_pitch, eskf_yaw


4. MAIN APPLICATION FLOW
--------------------------------------------------------------------------------

4.1 STARTUP SEQUENCE
--------------------
1. Initialize all modules
2. Load configuration
3. Create log directory if needed

4.2 PORT SELECTION PHASE
-------------------------
[1/4] PORT DETECTION
- Scan available ports
- Display port list with descriptions
- Auto-select single port
- Manual selection for multiple ports

4.3 CONNECTION TEST PHASE
--------------------------
[2/4] CONNECTION TEST
- Open selected port
- Receive data for 3 seconds
- Validate data format
- Calculate data rate
- Display results

4.4 DATA VALIDATION PHASE
--------------------------
[3/4] DATA VALIDATION
- Monitor stream for 10 seconds
- Show progress bar with real-time Hz
- Calculate statistics
- Detect performance issues
- Apply optimizations if needed

4.5 LOGGING PHASE
-----------------
[4/4] DATA LOGGING
- Display control instructions
- Real-time status display
- Handle user commands:
  * SPACE: Start/Stop logging
  * S: Show statistics
  * Q: Quit application


5. ERROR HANDLING
--------------------------------------------------------------------------------

Connection Errors:
- PORT_OPEN_FAILED: Port in use or doesn't exist
- NO_DATA: No data received in timeout period
- INVALID_FORMAT: Data doesn't match expected format
- LOW_DATA_RATE: Hz below threshold (90Hz)

Recovery Strategies:
- Automatic reconnection attempts
- Buffer overflow prevention
- Data gap handling
- Graceful degradation

7. PERFORMANCE OPTIMIZATIONS
--------------------------------------------------------------------------------

Serial Communication:
- Non-blocking reads (in_waiting check)
- Batch processing (multiple lines per iteration)
- Large buffer (65KB) to prevent overflow
- Minimal timeout (1ms)

Data Processing:
- Memory buffering (no real-time file I/O)
- Efficient parsing with regex compilation
- Deque for fixed-size buffers
- NumPy for statistical calculations

CSV Writing:
- Bulk write with csv.writerows()
- Write only on logging stop
- Separate thread for file operations (future)
